About StaticQuasar931

StaticQuasar931 is a browser game collection and creator project maintained by Static, also known as StaticQuasar931. Use the Game Finder to search the collection master list; the main games site hosts the game pages.

Visit the Main Games Page View the GitHub Site

What this site is

The site combines a searchable index of third-party browser games with original projects, support information, and an archive. Most game pages open on the main Google Sites collection.

What makes it different

The collection is organized around useful entry points: the Game Finder for known titles, genre browsing for discovery, and a short list of featured picks. The archive keeps older versions separate from current starting points.

The collection master list used by the Game Finder contains 960 unique entries and is dated September 19, 2026. The GitHub Pages site provides a searchable index, project pages, help, and archive links.
